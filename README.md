# Vobile AI Agent Skills

Welcome to Vobile's AI Agent Skills repository. Vobile is the global leader 
in digital content protection and acquired the leading music identification 
technology company Pex in 2025. Read more about the acquisition [here](https://pex.com/blog/vobile-completes-acquisition-of-pex/).

This repository provides a collection of modular Agent Skills — standardized instructions and resources
that allow AI agents (like Claude Code, GitHub Copilot, or custom LLM workflows) 
to effectively interface with Vobile’s ACR (Automatic Content Recognition) and AI-detection technologies.

## 📂 Repository Structure

  - **[`skills/`](https://github.com/Pexeso/ai-agents/tree/main/skills)**: The core skill definitions. Each subfolder contains a `SKILL.md` file that teaches an AI agent how to use specific Vobile capabilities.
      - `ai-song-detector/`: Use API endpoint to identify if an audio file (song) was generated by AI.
  - **`mcp.json`**: Configuration of the Vobile MCP server (see below).

All skills are shipped as a single bundle named **`vobile-agents`**, which also
registers the Vobile MCP server.

## 🚀 Installation

Steps presented here are for *global* skills installation.
For local (project) installation refer to your specific tool documentation.

### Claude Code & Codex

Claude Code and Codex can install straight from GitHub.
Both rely on the repo's:
- `.claude-plugin/marketplace.json`.

#### Claude Code

inside the app:

```
/plugin marketplace add Pexeso/ai-agents
/plugin install vobile-agents@vobile-agents
/plugin marketplace update
```

or from the terminal:

```bash
claude plugin marketplace add Pexeso/ai-agents
claude plugin install vobile-agents@vobile-agents
claude plugin marketplace update  # optional, for updates
```

#### Codex

from the terminal:

```bash
codex plugin marketplace add Pexeso/ai-agents
codex plugin add vobile-agents@vobile-agents
codex plugin marketplace upgrade  # optional, for updates
```

### OpenCode & Antigravity

OpenCode and Antigravity work from a local clone of the repository.
First clone the repository:

```bash
git clone https://github.com/Pexeso/ai-agents.git ~/src/ai-agents
```

You can pick different target directory for the cloned repository.
Update it accordingly in the commands below.

#### OpenCode

Point `~/.config/opencode/opencode.json` at the cloned repo location by adding a
`skills` key. OpenCode reads `opencode.json` or `opencode.jsonc`, whichever you have.

```json
{
  "$schema": "https://opencode.ai/config.json",
  "skills": { "paths": ["~/src/ai-agents/skills"] }
}
```

If the file already exists, add only the `skills` key — keep your existing
`provider` and other settings. Restart OpenCode after editing.

#### Antigravity

```bash
agy plugin install ~/src/ai-agents
```

#### Updating skills

Update both with `git pull`. OpenCode reads the clone directly, so it sees changes at once.
Antigravity copies the skills into its own store, so re-run `agy plugin install` after
pulling.

### Generic `npx skills` installation (Claude Code, Codex, OpenCode)

If installed, the [`skills`](https://github.com/vercel-labs/skills) CLI auto-detects which agents you
have installed and writes to each one's skills directory:

```bash
npx skills add Pexeso/ai-agents        # into the current project (local)
npx skills add Pexeso/ai-agents -g     # into your user config (global)
```

**Antigravity** does **not** support `npx skills` installation.

Alternatively, point your agent directly at the relevant directory or follow the
installation instructions within each individual `SKILL.md` file.

## 🚀 Why Use These Skills?

By importing these skills into your AI agent's environment, you enable it to:

1.  **Navigate Vobile Tools**: Understand Vobile's query syntax and metadata structures.
2.  **Automate Compliance**: Build workflows that automatically flag AI-generated content or copyright issues.
3.  **Enhance Attribution**: Leverage Vobile's industry-leading registry to accurately attribute content to rightsholders.

# Vobile MCP - Model Context Protocol

The Vobile MCP server is available at https://mcp.pex.com/mcp . See [mcp.json](https://github.com/Pexeso/ai-agents/blob/main/mcp.json) for the
ready-to-use server configuration — installing the `vobile-agents` plugin registers this server for you,
and other clients can copy the same entry into their own MCP configuration.

It provides the following tools:

- `detect_ai_song_from_url`
  - Detects whether audio from a URL is AI-generated.
  - Parameters: `url` (string): The URL of the audio file to analyze.
  - Returns: A dictionary containing the detection result, including fields like `is_ai` and `ai_score`.

- `detect_ai_song_from_base64`
  - Detects whether base64-encoded audio is AI-generated.
  - Parameters: `file_contents` (string): The base64-encoded audio data.
  - Returns: A dictionary containing the detection result.

*Client ID* and *Client Secret* must be filled-in when adding the MCP connector to the AI agent.
While adding the connector, the AI Agent will show the authorization consent page.

To get *Client ID* and *Client Secret* please reach out to the [Vobile Music Team](https://pex.com/contact/).

Authorization for the MCP server was tested with:

- Claude
- Grok - choose "Token Auth Method" = `client_secret_post` or `client_secret_basic`
- Gemini CLI
- ChatGPT
